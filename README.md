# ちゃっとジグソー 1.2.0

写真からジグソーパズルを作り、Delta Chatの相手やグループと協力して完成させるwebxdcアプリです。ブラウザ単体でも、一人でパズルを作って遊べます。

1.2.0では置き場を2段のページ式にし、100ピースでも縦に長くならないようにしました。「ピースを選ぶ → ボードをタップ」で配置でき、長いドラッグも不要です。

## はじめに

### Delta Chatで使う

1. [chatto-jigsaw-1.2.0.xdc](chatto-jigsaw-1.2.0.xdc) を、遊びたい相手またはグループのチャットへファイルとして送ります。
2. 双方で、送られた**同じアプリメッセージ**を開いて開始します。開始ボタンの名称は端末によって異なります。
3. どちらかがパズルを作成・配信します。相手は「みんな」から同じ写真の「▶ 続きから」を押します。

### ブラウザで使う

[index.html](index.html) をダブルクリックして開きます。別のJavaScriptファイルやローカルサーバーは不要です。画像の取り込み、作成、操作、途中保存ができます。

相手との協力同期、パズル配信、チャットへの結果投稿にはDelta Chatが必要です。ブラウザ単体では、右上に「ブラウザ単体」と表示します。

## 写真からパズルを作る

1. 画面下の「つくる」を押します。
2. 「ファイル」で画像を選びます。撮影したい場合は「カメラ」を押します。パソコンでは画像を点線の枠にドラッグしても取り込めます。
3. 「タテ」「ヨコ」のつまみ、または「3×3」などのボタンで分割数を選びます。各2〜10、合計4〜100ピースです。
4. 「作成 & 配信」を押します。Delta Chatでは相手へ配信し、ブラウザ単体ではこの端末だけで作成します。

初めての方には「3×3」の9ピースがおすすめです。画像の読み込みが終わるまで作成ボタンは使えません。写真は通信しやすいサイズへ縮小・圧縮されます。共有してよい写真を選んでください。

## ピースを置く

### タップで配置

1. 下の置き場にあるピースを1回タップします。枠の余白を押しても選べます。
2. 選んだピースにオレンジ色の枠が付きます。
3. 上のボードで、そのピースを置きたい場所をタップします。
4. 正しいマスなら固定されます。違っていたら選択を保つので、別の場所をタップできます。

同じピースをもう一度タップすると選択を解除します。タップでの配置はヒントを使った扱いにはなりません。間違った場所を試した場合も操作1回として数えます。

### ドラッグで配置

従来どおり、ピースを押さえたままボードへ運ぶこともできます。置き場では見やすい縮小・拡大表示、ドラッグを始めるとボードに合う実寸になります。正しい位置の近くで離すと固定されます。

## 置き場のページ

- スマートフォン程度の幅では6枚、広い画面では8枚ずつ、2段で表示します。
- 「次へ」「前へ」でピースを切り替えます。100ピースでも、下へ延々とスクロールする必要はありません。
- 固定されたピースは置き場から抜け、残りが詰めて表示されます。最後のページが空になったら前のページへ戻ります。
- ページを切り替えると選択を解除します。
- 「置き場 ○枚」は置き場にある未固定ピースの枚数です。ボード上に仮置きした未固定ピースは含みません。

## 便利なボタン

| 操作 | 働き |
| --- | --- |
| プレビュー | 小さな完成見本を表示・非表示にします。 |
| シャッフル | 未固定のピースを置き場へ集め、表示する順番を混ぜます。 |
| 整理 | 未固定のピースを置き場へ並べ直し、最初のページへ戻ります。 |
| 置き場に戻す | 未固定のピースを置き場へ戻します。固定済みは動かしません。 |
| ヒント | 1枚を正しい場所に固定します。チームのヒント数に加算します。 |
| 完成をシェア | 完成結果をチャットへ投稿します。Delta Chatで利用できます。 |

## 協力プレイと完成結果

だれかが正しい場所に固定したピースが、相手の画面にも反映されます。ドラッグ中の座標や未固定の置き方は共有しません。同じピースを同時に固定しても、1枚として合流します。

「チームヒント」は受信済みの全員のヒント使用数です。同じ更新の再受信では増えませんが、同じピースへ2人が同時にヒントを使った場合は2回と数えます。

完成後に「完成をシェア」を押すと、名前・自分の累計プレイ時間・チームヒント数を含む通知をチャットへ送ります。**完成しただけでは通知しません。** 同じ人・同じパズルIDの結果は、開き直しても重複投稿しません。

完成ログの「自分 ○回」は、その結果を投稿した人のヒント数です。時間と操作回数も端末ごとの値で、チーム全体の所要時間ではありません。通知のヒント数は投稿時点で把握した数で、遅れて届いたヒントはアプリ内の完成ログへ反映します。

右上の「同期待ち」は、送信待ち、または自分の更新の受信確認を待っている数です。標準では約10秒の送信間隔があり、連続操作はまとめて送信します。送信エラーは再試行します。相手への即時反映や到着を保証する表示ではありません。

## 再配信と一覧の管理

| 操作 | 動作 |
| --- | --- |
| ▶ 続きから | 同じパズルの保存した進行を開きます。 |
| ↗ 同じIDで再配信 | 同じパズルを送り直します。一覧は重複せず、進行・ヒント数を保持します。 |
| 新しく遊ぶ | 同じ写真で別のパズルを作って配信します。元の進行は残します。 |
| 一覧をクリア | 現在の一覧と完成ログを自分の端末で非表示にします。進行・送信待ち・ID記録は保持します。 |
| 非表示を戻す | 非表示にした一覧と完成ログを戻します。 |

クリアしたパズルは、開き直したり、同じIDを再受信したりしても勝手には再表示しません。新しいパズルや新たな完成結果は表示されます。相手の画面は変わらず、チャットや写真も削除しません。

## 途中保存と移行

- 固定状態、未固定の配置、自分の時間・操作回数・ヒント数、置き場のページ・順番、送信待ちを端末内に保存します。
- 開き直すと、最後に遊んだ非表示でないパズルを復元します。閉じていた時間は加算しません。アプリ内で別タブを見ている間は進みます。
- 時間は約5秒ごと、配置は操作後や画面を離れるときなどに保存します。強制終了では直前の数秒が失われる場合があります。
- 「保存失敗」が出たら、端末の空き容量やブラウザの保存設定を確認してください。
- HTMLの移動・名前変更・ブラウザ変更で、保存領域が変わる場合があります。
- Delta Chatの送信済みの固定・ヒントは通信履歴から復元できます。未送信の操作や端末だけの配置・時間・非表示設定は復元できません。ブラウザ単体には通信履歴からの復元はありません。

新しいxdcを別メッセージとして送った場合、旧メッセージの進行は自動で移りません。同じHTML・同じ保存領域に以前の進行がある場合、固定状態や時間を保って新しい置き場へ並べ直します。

## 困ったとき

| 症状 | 確認・操作 |
| --- | --- |
| 作成ボタンが使えない | 画像の読み込みを待ちます。失敗したら別の画像を選びます。 |
| ピースが見つからない | 「次へ」「前へ」で探すか、「整理」を押します。 |
| タップしても置けない | オレンジの枠を確認し、正しいマスをタップします。 |
| 相手に届かない | 同じ1.2.0のアプリメッセージを開いているか、通信できるか確認します。 |
| 完成を投稿できない | 完成済みか、投稿済み・送信待ちではないか確認します。ブラウザ単体では投稿できません。 |

## 確認したこと

100ピース、幅390pxのブラウザで置き場は高さ266pxでした。タッチ操作による選択・配置、ドラッグ、ページ切り替えと再読込復元、最後のページにあるピースの協力固定、画面幅変更、縦長・横長の分割を検証しました。3画面の模擬webxdc協力通信も検証し、JavaScriptエラーは0件でした。

Delta Chat実機、実際の通信相手への到着、スマートフォン実機での指操作は未確認です。タッチ操作の確認にはブラウザのタッチ入力機能を使用しています。
